# 需求规格说明

## 项目定位
综合性股票交易工作站，面向 A 股市场（架构预留多市场扩展）。

## 功能需求

### 量化引擎 (P0-P3)
- 策略基类框架：C++虚基类 IStrategy，onBar/onTick/onOrder 事件钩子
- 回测引擎：日线/分钟级别，事件驱动循环，下一Bar开盘价成交
- 模拟交易引擎：实时行情驱动，当前价+滑点模拟成交
- 费用模型：佣金(万2.5/最低5元)+印花税+过户费+经手费+证管费，全参数可配置
- 绩效统计：年化收益/最大回撤/夏普/卡玛/Alpha/Beta/VaR/索提诺
- 选股引擎：多因子打分+条件筛选+综合排名+调仓周期
- 因子库：50+预置因子（估值/成长/动量/质量/情绪/波动）
- 参数优化：网格搜索+遗传算法
- 策略对比、蒙特卡洛模拟、压力测试

### 行情看盘 (P5-P8)
- K线图：9层渲染系统（K线/指标/指数叠加/持仓标注/交易标记/画线/交互）
- 分时图、多周期切换
- 全局搜索：代码/名称/拼音首字母模糊匹配
- 市场全景：涨幅榜/跌幅榜/板块指数/概念热力图
- 市场指数条：上证/深证/创业板/科创50 实时报价
- 指数叠加对比：归一化对齐，相对强弱副图

### 数据 (P1)
- 免费数据源：AKShare/Tushare HTTP API
- 本地存储：SQLite
- 数据类型：日线/分钟线/Tick，基本面，龙虎榜，北向资金，融资融券

### 工具 (P8)
- 画线工具、区间统计、筹码分布、成交分布
- 交易日志、自定义指数、定时任务
- 数据导出CSV/Excel、K线截图
- 自定义快捷键、多窗口模式

### AI 智能 (P9)
- 舆情情绪分析、K线形态识别、ML选股、策略参数优化建议

### 扩展 (P10)
- 实盘交易（券商API对接）、盘口数据、多数据源
